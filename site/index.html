Arquitetura

Como a plataforma funciona

GitHub Pages hospeda somente a interface. O processamento ocorre no n8n e na API privada.

01Painel webInterface estática no GitHub Pages.
→
02API documentalExtração, OCR e artefatos protegidos.
→
03n8nOrquestra workflows e agentes.
→
04SupabaseDados, evidências e histórico.
→
05RelatóriosChecklist, PDF, JSON e dashboard.

Camada web

  • Deploy automático a cada push no main.
  • Sem chaves gravadas no repositório.
  • Token mantido somente durante a sessão.
  • Envio direto para a API configurada.

Camada de processamento

  • n8n em modo fila com Redis e workers.
  • API FastAPI para documentos industriais.
  • Agentes especializados e consolidador.
  • Validações objetivas antes do relatório.
Importante: o GitHub Pages não executa Docker, n8n, Python ou banco de dados. O backend deve ser publicado em um servidor/VPS e sua URL configurada neste painel.
